Setelah login, user akan diarahkan ke halaman berbeda tergantung rolenya:

│ ROLE           │ REDIRECT PAGE         │ URL                           │

│ Admin (A)      │ Dashboard Admin       │ /dashboard/                   │
│ User (U)       │ Chatbot Page          │ /                             │
│ Support (S)    │ Chatbot Page          │ /                             │
│ Manager (M)    │ Chatbot Page          │ /                             │
└─────────────────────────────────────────────────────────────────────────┘

-------
