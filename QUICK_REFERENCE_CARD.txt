## Decision Tree: Is Migration Needed?

```
Current pattern count?

  < 30 keywords     → ✅ Continue for 1+ year
  30-50 keywords    → ✅ Continue for 6-12 months
  50-100 keywords   → ⚠️ Plan migration by month 6
  > 100 keywords    → ❌ Migrate NOW

Pattern updates per month?

  < 1               → ✅ Maintenance is fine
  1-2               → ✅ Still manageable
  2-5               → ⚠️ Getting tedious
  > 5               → ❌ Need automation

User complaints about false rejections?

  < 1%              → ✅ Accuracy is good
  1-5%              → ✅ Acceptable
  5-10%             → ⚠️ Monitor closely
  > 10%             → ❌ Address soon
```
