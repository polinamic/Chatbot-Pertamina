NAMA FORM: Acces Control Device
TRIGGER KEYWORD: access, control, acs, pintu, kartu akses, door, absen, fingerprint akses, rfid, kontrol pintu, kunci elektronik, badge, id card pintu, sensor pintu
KONTEKS MASALAH: Permasalahan yang berkaitan dengan perangkat kontrol akses fisik seperti: kartu akses tidak terbaca di pintu, pintu tidak bisa dibuka meskipun kartu aktif, mesin fingerprint untuk akses area tidak merespons, atau permintaan pendaftaran kartu/badge baru untuk area tertentu.
PANDUAN UI:
1. Login ke portal IT Support, klik menu utama di pojok kiri atas (☰).
2. Pilih kategori "Infrastruktur & Keamanan Fisik".
3. Klik kotak "Acces Control Device".
4. Pilih jenis permintaan: [Gangguan Perangkat] atau [Pendaftaran Akses Baru].
5. Isi lokasi perangkat/pintu yang bermasalah dan deskripsi singkat kejadian.
6. Klik "Buat Tiket".
CATATAN KHUSUS: Form ini KHUSUS untuk perangkat kontrol akses fisik (pintu, turnstile). Untuk masalah akses ke sistem/aplikasi, gunakan form "Acces Management End User Details" atau "User ID ERP & Non ERP".

NAMA FORM: Access Management End User Details
TRIGGER KEYWORD: access, akses, internet, working group, wifi, p_6c, vpn, mailing, group, file, sharing, global, member, email, e-mail, sharepoint, ftp, grup email, mailing list, distribution list, shared mailbox, hak akses sistem, permission, akses folder, working drive, onedrive, cloud
KONTEKS MASALAH: Permasalahan atau permintaan terkait hak akses ke layanan digital perusahaan, antara lain: penambahan ke grup email / mailing list, permintaan akses VPN, akses ke SharePoint, FTP, folder sharing, atau pengelolaan keanggotaan working group IT.

NAMA FORM: Approval Change (PJS, Cuti, etc)
TRIGGER KEYWORD: approval, pjs, cuti, pengganti jabatan sementara, change approval, persetujuan, pendelegasian, delegasi akses, jabatan sementara, acting, pejabat sementara
KONTEKS MASALAH: Permintaan perubahan atau approval terkait kondisi kerja sementara seperti: pengajuan PJS (Pejabat Jabatan Sementara), perubahan hak akses selama cuti, atau proses pendelegasian wewenang dalam sistem yang memerlukan approval dari IT.
PANDUAN UI:

CATATAN KHUSUS: Permintaan PJS wajib disertai nomor SK dari HR. Perubahan hak akses selama cuti tidak lebih dari 30 hari; lebih dari itu gunakan form "User ID ERP & Non ERP".

NAMA FORM: Change, Reset, Unlock Password Details
TRIGGER KEYWORD: user id, erp, non-erp, reset, password, lock, unlock, reset password, change password, email, unlock, user, aplikasi, lupa password, ganti password, akun terkunci, locked, password expired, kadaluwarsa password, login gagal, tidak bisa login, @risk palisade, absensi fingerprint, aspen, sap, komet, ess, employee self service, i-serv, i-tracking, portal, aplikasi perusahaan (dan semua nama aplikasi ERP/Non-ERP yang terdaftar)
KONTEKS MASALAH: Segala permintaan yang berkaitan dengan pengelolaan kata sandi (password) dan status akun pada sistem perusahaan, meliputi: lupa password, password kedaluwarsa, akun terkunci (locked out), reset password akun Windows/domain, reset password aplikasi ERP maupun Non-ERP (SAP, KOMET, ESS, dan ratusan aplikasi lainnya), serta perubahan password email perusahaan.
PANDUAN UI:
1. Di halaman utama portal IT Support, klik tombol "Akses & Keamanan".
2. Pilih sub-menu "Manajemen Akun Pengguna".
3. Klik "Change, Reset, Unlock Password".
4. Pilih jenis permintaan: [Reset Password] / [Unlock Akun] / [Ganti Password].
5. Pilih sistem/aplikasi yang bermasalah dari dropdown (contoh: Windows Domain, SAP ERP, Email, KOMET).
6. Verifikasi identitas dengan memasukkan ID Karyawan.
7. Klik "Ajukan Reset".
CATATAN KHUSUS: Untuk reset password domain Windows, user harus dapat dihubungi via telepon untuk verifikasi identitas. Unlock akun Active Directory biasanya dapat diproses dalam 30 menit pada jam kerja. Jika masalah dapat diselesaikan sendiri (misal: password expired), ikuti panduan troubleshooting di KB Troubleshoot sebelum membuat tiket.

CATATAN KHUSUS: Jika gangguan berdampak pada banyak user atau operasional bisnis kritis, pilih tingkat dampak "Kritis" agar mendapat penanganan prioritas. Tim IT akan menghubungi pelapor dalam waktu 15 menit untuk insiden kritis.

TRIGGER KEYWORD: user id, erp, user, id, non erp, akses, otorisasi, autorisasi, pengalihan, perpanjangan, akun, email, aplikasi, sap, SAP, tambah akses, cabut akses, extend akses, buat user baru, user baru sap, role sap, authorization, otorisasi sap, pembuatan akun, non-erp user
KONTEKS MASALAH: Segala permintaan terkait User ID dan otorisasi pada sistem ERP (SAP) maupun Non-ERP: pembuatan user ID baru, penambahan role/otorisasi akses, perpanjangan masa aktif user, pencabutan hak akses, pengalihan akses antar user, atau perubahan jabatan yang berdampak pada hak akses sistem.
PANDUAN UI:
1. Di portal IT Support, klik menu "Akses & Keamanan".
2. Pilih sub-menu "Manajemen User ID".
3. Klik "User ID ERP & Non ERP".
4. Pilih jenis permintaan: [Buat User Baru] / [Tambah Role/Otorisasi] / [Cabut Akses] / [Perpanjangan] / [Pengalihan Akses].
5. Isi detail lengkap: nama user, sistem (SAP/Non-ERP apa), role yang diminta, dan periode akses.
6. Lampirkan persetujuan atasan langsung dan dokumen pendukung (SK, surat tugas).
7. Klik "Ajukan Permintaan User ID".
CATATAN KHUSUS: Setiap permintaan otorisasi SAP Production WAJIB memiliki approval dari atasan minimal setingkat Supervisor dan fungsi SAP Functional Lead terkait. Proses verifikasi keamanan memakan waktu 3-5 hari kerja untuk SAP Production.

NAMA FORM: Video Conference atau Audio Conference
TRIGGER KEYWORD: video, conference, audio, townhall, meeting, zoom, webex, teams meeting, microsoft teams, video call, rapat virtual, conference call, video conference gagal, audio conference, suara putus, gambar macet, link meeting, schedule meeting, undangan meeting
KONTEKS MASALAH: Permasalahan atau permintaan terkait layanan video/audio conference: tidak bisa bergabung ke meeting, suara/gambar putus-putus, permintaan setup ruang video conference, lisensi meeting yang diperlukan, atau bantuan teknis untuk penyelenggaraan townhall/webinar besar.
PANDUAN UI:
1. Di portal IT Support, buka tab "Fasilitas Ruang Rapat".
2. Pilih "Video Conference & Audio Conference".
3. Pilih jenis masalah/permintaan: [Gangguan Teknis Meeting] / [Setup Ruang Video Conference] / [Townhall/Webinar Besar].
4. Isi detail: platform yang digunakan (Teams/Zoom/Webex), jumlah peserta, tanggal dan waktu meeting.
5. Untuk gangguan: sertakan ID meeting/link yang bermasalah dan gejala yang dialami.
6. Klik "Ajukan Permintaan Video Conference".
CATATAN KHUSUS: Untuk townhall dengan peserta lebih dari 300 orang, ajukan permintaan minimal 7 hari kerja sebelumnya agar tim IT dapat mempersiapkan infrastruktur yang memadai dan melakukan uji coba.

NAMA FORM: Wifi Access
TRIGGER KEYWORD: wifi, guest, temporer, tamu, jaringan, wifi guest, wifi tamu, akses wifi, koneksi wifi, password wifi, jaringan wifi, wifi kantor, ssid, tidak bisa konek wifi, wifi lambat, signal wifi lemah, koneksi wireless, wireless
KONTEKS MASALAH: Permintaan atau permasalahan terkait akses WiFi: permintaan kredensial WiFi untuk tamu/visitor, koneksi WiFi yang tidak stabil atau lambat di area tertentu, permintaan akses WiFi temporer untuk acara/event, atau WiFi di area tertentu yang tidak berfungsi.
PANDUAN UI:
1. Di portal IT Support, klik tombol menu (☰) di pojok kiri atas.
2. Pilih menu "Infrastruktur IT".
3. Klik kotak "Wifi Access".
4. Pilih jenis permintaan: [Akses WiFi Tamu/Guest] / [Gangguan WiFi Area Tertentu] / [WiFi Temporer untuk Acara].
5. Isi lokasi (gedung, lantai, area), nama pemohon, dan kebutuhan spesifik.
6. Untuk akses tamu, sertakan nama tamu, instansi, dan periode kunjungan.
7. Klik "Buat Tiket Wifi".
CATATAN KHUSUS: Akses WiFi untuk tamu bersifat terbatas dan terisolasi dari jaringan internal perusahaan. Masa aktif akses tamu maksimal 7 hari dan dapat diperpanjang jika diperlukan.

LOGIKA PENCOCOKAN KEYWORD:
1. Chatbot akan mencocokkan kata kunci dari pesan user dengan daftar TRIGGER KEYWORD di atas.
2. Jika ditemukan satu atau lebih kecocokan, arahkan user ke PANDUAN UI form yang sesuai.
3. Jika keyword cocok dengan LEBIH DARI SATU form, tampilkan pilihan kepada user untuk mengklarifikasi.
4. Jika tidak ada keyword yang cocok, arahkan ke form "IT Helpdesk Query" untuk bantuan lebih lanjut.

PRIORITAS PENCOCOKAN:
- Keyword yang lebih spesifik (nama aplikasi, nama teknis) > keyword yang lebih umum
- Contoh: "reset password SAP" → prioritas ke "Change, Reset, Unlock Password Details" bukan "Incident"
- Contoh: "sap error" → prioritas ke "Incident" karena menunjukkan gangguan, bukan permintaan reset

CONTOH SKENARIO:
- User: "saya lupa password" → Arahkan ke "Change, Reset, Unlock Password Details"
- User: "SAP tidak bisa dibuka" → Arahkan ke "Incident"
- User: "minta akses sharepoint" → Arahkan ke "Access Management End User Details"
- User: "kartu akses pintu tidak terbaca" → Arahkan ke "Acces Control Device"
- User: "proyektor di ruang rapat A tidak menyala" → Arahkan ke "Multimedia and Sound System"
- User: "email penuh" → Arahkan ke "Upgrade Quota Online Mailbox"
- User: "minta install autocad" → Arahkan ke "Software"
